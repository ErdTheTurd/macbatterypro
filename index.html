Mac Battery Pro

See what is using your Mac’s battery, CPU, and memory, in plain words, and what you can do about it.

What it does

A friendlier Activity Monitor. It shows what is draining your Mac, in plain words, and offers simple suggestions.

Battery
See what is using the battery. It says so in plain words, and suggests what you can do.
CPU
See what is using the processor, in the same plain language, with a simple suggestion.
Memory
See what is using memory, explained clearly, with a simple suggestion for what to do.

How it respects you

  • It works offline.
  • It is read-only by default.
  • It never quits or closes an app without your confirmation.
  • No account is needed.

Accessibility

Mac Battery Pro is built for VoiceOver, so you can listen to it. It is built for large text, so you can read it at a size that suits you.
